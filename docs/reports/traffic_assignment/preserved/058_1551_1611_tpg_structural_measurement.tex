\paragraph{TPG structural measurement.}
For the TPG case, the operator has shape $3{,}690\times15{,}772$, or
$58{,}198{,}680$ logical entries. Only 158,219 entries are nonzero, giving a
density of 0.271860\%. The logical dense float32 size is 222.01 MiB, whereas
the direct BCOO representation occupies 1.811 MiB. This observed sparsity,
rather than an a-priori assumption, motivates BCOO as the automatic
representation.
